# 机构简称与全面脱敏改进验收审查

审查对象：本任务独立克隆的 codex/org-alias-detection 分支，基线 576e2668c351d113d2f0da4322154652c00f3aee。未审查或修改用户的其他检出目录。按需求优先工作流串行自审，没有使用独立 reviewer。

## 已修复的发现

1. 模型会数错全称内部与简称各自的出现次序。程序改为枚举准确位置、标记待判断原词，让模型按候选编号判断。
2. 只复核漏项和矛盾项仍会放过模型肯定但误判的普通词。实际 Word 文件曾误改“发展远景”“小麦（粮食）”“联合开发”，不是理论假设。现在简称每次出现均参加逐项核对；失败样例已保留，修正后实际 Word 输出普通词均保留，16 处机构出现被处理，逐块还原和原件哈希验证通过。
3. 相同位置先后收到 A、B、A 三个主体时，第三个重复答案可能重新进入结果。现在记住冲突位置，不把重复当证据。
4. 主体资料过长及分组返回同一全称可能造成后组遗漏或重复编号。拆分称呼列表保留全部词，按原文全称归入已有主体；同形简称不能据此归并。
5. 本地模式可能发送类默认占位模型名。改为探测当前实际加载模型；已通过受控请求验证。
6. 旧 PDF 向已打开源路径保存会报错。新旧 PDF 入口均使用新目标，正式流程按具体位置写回；还原检查对应区域的代号。
7. PPT 软换行、字段文字与 runs 枚举不一致。读取和写回统一使用文字节点，保留原软换行；往返测试通过。
8. “123万美元”不能被拆成“123万”后按人民币处理；已经模糊的“100万余美元”不能反复识别成新金额。新增复合单位和残留误报回归。
9. 真实 GUI 进度条使用不支持的 value 参数，引发回调异常。改用组件实际支持的 set；长状态文字移到整行，取消没有实际作用的旧简称开关。
10. 旧映射曾共用代号时，不能报告成完整准确还原。仍生成可恢复的文件，同时显示历史歧义说明。
11. 短文字 PDF 不应仅因不足 50 字转入 OCR；混合文档的完整扫描图片页不能漏判。按页检查文字和大幅图片，扫描路线继续输出 Markdown。

## 结构、安全及兼容性

正式文件流程使用同一份原文块、机构结果和具体位置；MD 从相同定位结果生成。旧文本脱敏接口转为新流程适配，不再先做上下文识别后全局按词替换。

新增文档识别、固定规则、定位写回三个实际职责模块；没有引入整套 NER 框架或通用任务调度。文本适配入口替代旧的大段重复处理，旧 PDF 临时复制、同路径保存及永久清理分支移除；保留仍供旧接口使用的辅助函数。

原件只读，已有输出先备份并校验。Excel 使用独立隐藏实例，禁用宏、事件及外部链接更新，关闭自己的工作簿和实例。仅敏感命中格必要时转值，保存原公式和类型；普通公式及引用尽量保留。跨文件新建映射，不沿用前一文件的主体。

模型仅对可恢复网络错误有限重试；鉴权或配置错误不在后续输出复查中重复请求。取消后不发起下一轮请求。合法空结果与损坏 JSON 分开，输出截断和定位错误如实记录。

密钥通过验证进程的标准输入传递，不写入样例、命令文件或源码。最终校验检查源码文件是否混入会话密钥，仅输出命中路径和数量，不输出密钥本身。

## 已完成的验收范围

- 实际 Word、Excel、PPT、PDF 写回，保存映射后重载还原；TXT、MD 及扫描 OCR→MD 路线。
- Excel 无缓存公式由本机 Excel 复算，验证引用、普通 SUM、敏感拼接公式和数字类型恢复，原件哈希未变。
- Word/PPT 由本机 Office 导出 PDF，实际查看渲染，文字未丢失、原字体样式保留；PDF 代号和原文还原可读取，查看渲染无截断。
- 原启动器实际创建 GUI，局部失败仍显示输出文件和映射；修正后回调异常为 0，状态与日志可见。
- 3 份固定虚构标注使用指定真实模型比较，另外运行实际 Word 的完整模型→写回→重读→复查→还原流程。

最终离线数量、源码哈希及最终模型结果以交付记录和对应原始 JSON 为准。测试未通过的历史记录保留，不被后续结果覆盖。

## 实际边界

固定标注集规模有限；任意简称不能保证零漏检。新流程调用更多、明显慢于原流程，必须与效果同时披露。

扫描 OCR 路线的回归使用受控 OCR 文本，未将真实扫描图片识别准确率称为已验证；扫描输出为 Markdown。特殊嵌入对象、图表内非文字对象及任意扫描图片版面还原不在本次承诺范围内。

PDF 的原文字可还原，但原字体、字距和二进制结构不保证一致。历史共用代号造成的原词歧义无法事后补造。
