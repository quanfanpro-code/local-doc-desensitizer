## 范围与成功标准

1. 明确账号字段中的短账号脱敏，银行卡校验不代替企业账户识别；普通数量和产品编号不误改。
2. 金额字段下的普通数字进入现有金额处理，保留币种、百万门槛和准确还原。
3. MAC 不吞标签、不漏尾部，支持中文相邻和一致分隔符；车牌允许中文行文、小写和分隔点，保留既有特殊尾字。
4. 完整固定格式命中不被错误模型跨度截断；不确定重叠明确报告并保护敏感范围。
5. 含 OCR 文字层的整页扫描 PDF 正确分流到脱敏 MD，不再交付原图残留的“脱敏 PDF”。
6. 文字 PDF 不误删邻行，保存后核对未改原文，能恢复原文字。
7. Excel 同时检测公式文字常量和计算值，保护引用及普通公式，恢复原公式和类型。
8. Word 脚注、尾注提取、写回、复查与还原一致。
9. 普通文字 PDF 能选择纯正则；无模型不阻断扫描件同批的普通文件，OCR 可用时可作纯规则扫描处理。
10. 批量还原取消时显示取消与处理数量。
11. 分隔身份证按完整号码校验并还原；无效日历日期不误当有效日期处理。
12. 清理报告已确认的无调用旧代码；更新来源与许可说明，不引入整个框架。
13. README 原有更新记录集中记录本轮变化，正文同步实际能力；不将未验证能力写成通过。
