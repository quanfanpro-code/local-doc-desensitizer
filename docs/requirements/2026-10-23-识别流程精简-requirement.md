# 识别流程精简需求

用户已明确批准直接实施：取消模型 JSON 回答、重复发现、逐处重复识别和模型输出复查；以减少至少 90% 的重复处理、整体提速 100 倍为目标，同批材料对比效果，不能靠漏处理提速。

范围是现有 Windows 程序的 LLM 识别链及必要调用方。机构、任意简称、同形普通词、同名不同主体、人名、地址、固定规则、原格式写回和还原仍保留。原文件保护与已有输出备份不变。不安装依赖、不改变密钥或接口、不提交推送。

验收分别记录模型请求数、输入输出量、端到端时间、漏检、误检、错误关联和重载映射后还原结果。以现有三份人工标注及重复简称材料进行同接口同参数比较；短材料的请求比例和压力材料分别披露，未达到 100 倍就明确写未达到，不用模拟耗时替代真实计时。

证据：现有流程对 8,019 字重复简称材料发起 35 次请求，其中 29 次重复核对简称；这是离线固定正确答案下的流程计数。现有标注文件不修改。不存在待用户确认的范围问题，实施细节由本次授权覆盖。

用户追加要求：同步优化并报告输入、输出、思考及总 token；真实接口测试控制在旧流程五分钟内的量级。已停止正在执行的 1,000 次重复压力样例，最终只比较三份原有虚构标注，共 7,584 字、36 处，同参数旧流程实际 260.1136 秒。更早的大样例试验只保留原始记录，不作为最终成功提速口径，也不再扩大测试。测试工具默认压力次数改为 0。
