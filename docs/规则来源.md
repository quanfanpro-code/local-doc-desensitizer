## 词典的使用边界

原有行政区划、地名、法律形式和行业词用于机构候选边界，保留来源信息。本次新增 12 个自行整理的审计普通用语，只给模型提示常见语境；某词在具体文件确实是机构代称时，仍按上下文识别，不因进入词典而直接排除。

datamask 的审计排除词表有 273 项、272 个不同词，姓氏表 295 项、284 个不同词；本项目原词典有 3,628 项、3,603 个不同条目，其中地名 3,261、行业词 183。以上为改前快照统计，不能把词典总量当成机构简称识别质量。没有把对方的排除词或姓氏整表直接复制过来，也没有用姓氏表取代上下文中的人名判断。

本项目保留原来的邮箱、IPv4 基础表达式；车牌和 MAC 在 2026-09-19 按下列上游片段适配，并补充中文边界回归。银行卡 Luhn 仅用于银行卡候选，明确的对公收付款账号不因 Luhn 不通过而漏掉；身份证、信用代码校验异常但字段标签明确时仍处理，并记录来源说明。

## 没有采用的部分

datamask 不提供能够替代大模型的任意简称自动关联能力。本次的全文两轮识别、逐处语境判断、按候选编号补充判断及同名不同主体处理，是针对本项目需求实现的改进，不能归功为直接拿来的对方能力。

datamask README 声明 MIT，但核对的仓库根目录没有独立 LICENSE 文件。因此本次借鉴设计，未复制其实现或词典数据。

datamask 提到 houbb/sensitive 和 AuditMask。已检查 [houbb/sensitive](https://github.com/houbb/sensitive) 的 Java 字段/日志扫描及示例，但没有核实 datamask 某条正则与其具体源码的逐条移植对应关系；AuditMask 对应公开仓库未核实。两者均不标注为本次已采用依赖。

## 2026-09-19 实际复用的规则片段

先在 GitHub 核对源码及同样例效果，再作以下最小适配，没有安装完整框架，也没有新增运行依赖。

- **JioNLP 车牌**：来自上述固定提交 `jionlp/rule/rule_pattern.py` 的车牌字符集及可选中点、句点、空格、全角空格。保留原作者 dongrixinyu、Apache License 2.0 的来源说明；本项目增加 ASCII 左边界防止长编号误命中，并保留已有挂、学、警、港、澳尾字。完整原许可证：[JioNLP Apache-2.0](licenses/JioNLP-Apache-2.0.txt)。
- **Presidio MAC**：来自 [mac_recognizer.py](https://github.com/data-privacy-stack/presidio/blob/f251c513e8aad6820e9b2a44983ebf3a93637b07/presidio-analyzer/presidio_analyzer/predefined_recognizers/generic/mac_recognizer.py) 的冒号/短横线一致性反向引用及 Cisco 点分格式。本项目将单词边界改为 ASCII 字母数字边界，允许中文紧邻；不移植其评分系统及全零/广播地址过滤。Copyright (c) Presidio Contributors，完整原许可证：[Presidio MIT](licenses/Presidio-MIT.txt)。
- **账号**：Presidio 信用卡长度和 Luhn 不能代替所有对公账号。本项目沿用既有字段判断，明确账号字段允许短号，产品编号及无字段短数字保持原文；这部分没有宣称复制信用卡实现。
- **金额与日期**：沿用项目既有 Decimal 金额处理；数字金额增加当前列或紧邻字段证据，数量不凭长度当金额。日历有效性使用 Python 标准库 `datetime`，没有从头实现历法。

边界测试包括中文相邻车牌、小写、分隔符、`MAC:` 标签、混用 MAC 分隔符、Cisco 格式、短账户、金额列数字及普通数量；完整结果见修复验收报告。
