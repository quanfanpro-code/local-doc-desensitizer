## 词典的使用边界

原有行政区划、地名、法律形式和行业词用于机构候选边界，保留来源信息。本次新增 12 个自行整理的审计普通用语，只给模型提示常见语境；某词在具体文件确实是机构代称时，仍按上下文识别，不因进入词典而直接排除。

datamask 的审计排除词表有 273 项、272 个不同词，姓氏表 295 项、284 个不同词；本项目原词典有 3,628 项、3,603 个不同条目，其中地名 3,261、行业词 183。以上为改前快照统计，不能把词典总量当成机构简称识别质量。没有把对方的排除词或姓氏整表直接复制过来，也没有用姓氏表取代上下文中的人名判断。

本项目保留原来的邮箱、车牌、IPv4、MAC 类别与基础表达式，并新增边界回归；这些表达式没有补造外部来源。银行卡 Luhn 仅用于银行卡候选，明确的对公收付款账号不因 Luhn 不通过而漏掉；身份证、信用代码校验异常但字段标签明确时仍处理，并记录来源说明。

## 没有采用的部分

datamask 不提供能够替代大模型的任意简称自动关联能力。本次的全文两轮识别、逐处语境判断、按候选编号补充判断及同名不同主体处理，是针对本项目需求实现的改进，不能归功为直接拿来的对方能力。

datamask README 声明 MIT，但核对的仓库根目录没有独立 LICENSE 文件。因此本次借鉴设计，未复制其实现或词典数据。

datamask 提到 houbb/sensitive 和 AuditMask。已检查 [houbb/sensitive](https://github.com/houbb/sensitive) 的 Java 字段/日志扫描及示例，但没有核实 datamask 某条正则与其具体源码的逐条移植对应关系；AuditMask 对应公开仓库未核实。两者均不标注为本次已采用依赖。
