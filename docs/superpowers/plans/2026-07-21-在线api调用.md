## 二、任务清单

### 阶段 A：mineru桥接.py（新增在线 API 函数）

- **[1] 写 `规范化在线api地址` 测试 -> 实现 -> 验证**
  - 测试覆盖：`http://119.6.186.168:40040`、`http://119.6.186.168:40040/v1`、`http://119.6.186.168:40040/v1/chat/completions`（截断）、`https://api.openai.com`、`api.openai.com`（补协议）、空字符串、通义千问 `/compatible-mode/v1`
  - 实现：正则 `r"^(https?://.*?/v1)"` 非贪婪提取到 /v1 为止，没匹配补 /v1
  - 验证：`python -m pytest 开发测试/test_在线api函数.py -k 规范化 -v` 通过

- **[2] 写 `获取在线api模型列表` 测试 -> 实现 -> 验证**
  - 测试：mock `requests.get`，验证请求头含 `Authorization: Bearer {key}`、URL 拼接正确（`{规范化地址}/models`）、返回格式转换、空 key 抛异常
  - 实现：调 `规范化在线api地址` + `requests.get` 带 Authorization 头
  - 验证：测试通过

- **[3] 写 `探测在线api状态` 测试 -> 实现 -> 验证**
  - 测试：mock `获取在线api模型列表`，验证：空模型列表、模型在列表里、模型不在列表里、网络异常
  - 实现：调 `获取在线api模型列表`，返回 `{"已启动": bool, "模型名称": str, "模型已加载": bool}`
  - 验证：测试通过

### 阶段 B：ner引擎.py（改造 LLM 后端选择）

- **[4] 写 `_读取llm配置` 测试 -> 实现 -> 验证**
  - 测试：本地模式返回 `探测lm_studio地址()` 结果；在线模式返回规范化地址+密钥+模型；旧版 settings.json（无 llm_mode）默认本地
  - 实现：读 settings.json，根据 `llm_mode` 返回不同字段
  - 验证：测试通过

- **[5] 写 `_调用llm` 在线模式请求头测试 -> 改造 4 个方法 -> 验证**
  - 测试：mock `requests.post`，验证在线模式请求头含 `Authorization: Bearer {key}`、本地模式不含
  - 改造：`_获取api地址()`（用 `_读取llm配置`）、`_检测lm可用性()`（根据模式分支）、`_调用llm()`（加 headers）、`_审核简称候选()`（加 headers）
  - 验证：测试通过

- **[6] 运行现有 `开发测试/` 所有测试 -> 确认本地模式回归通过 -> 修复回归**
  - 运行：`python -m pytest 开发测试/ -v`
  - 如有失败：定位回归点，修复
  - 验证：全部通过

### 阶段 C：app.py（改造 GUI）

> GUI 部分用"实现 + 手动验证"格式，不写单元测试（customtkinter 无 headless 模式，现有 `开发测试/` 也无 GUI 测试，遵循现有模式）

- **[7] 改造 `build_ui` 配置区 -> 手动验证 UI 显示**
  - 实现：把 "LM Studio 配置" 区改成 "LLM 配置" 区，加 `CTkSegmentedButton`（本地/在线）+ 两个子 frame（`lm_frame_local`/`lm_frame_online`）+ 在线输入框组件（API 地址/密钥/模型名下拉框/拉取按钮/测试连接按钮/显示密钥勾选框）
  - 验证：启动程序，切换本地/在线，两个子 frame 正确显示/隐藏

- **[8] 实现 `_切换llm模式` 回调 -> 手动验证切换**
  - 实现：检查 `is_processing`（True 则拒绝+弹窗+回滚 segmented）-> 保存 `llm_mode` -> `grid_forget` 当前子 frame -> `grid` 另一个 -> 重置状态标签 -> 异步调 `_检测lm状态`
  - 验证：切换后子 frame 切换、配置持久化、状态灯更新

- **[9] 实现 `_保存在线配置` + `_切换密钥显示` -> 手动验证**
  - 实现：输入框失焦保存到 settings.json；"显示"勾选框切换密钥框 `show` 属性
  - 验证：重启程序配置还在；密钥可显示/隐藏

- **[10] 实现 `_拉取模型列表` -> 手动验证**
  - 实现：检查地址/密钥非空 -> 调 `获取在线api模型列表` -> 填下拉框 -> 选中匹配 `online_model` 的项；失败则下拉框切换为可手填 `CTkEntry`
  - 验证：拉取成功填下拉框；拉取失败降级可手填

- **[11] 改造 4 个状态方法 -> 手动验证状态灯**
  - 改造：`_测试lm连接`（根据模式分支）、`_检测lm状态`（根据模式调对应函数）、`_更新lm状态`（文案根据模式）、`_刷新lm状态`（文案根据模式）
  - 验证：本地模式状态灯正确；在线模式状态灯正确；测试连接成功给费用提示
