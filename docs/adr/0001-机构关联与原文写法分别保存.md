# 机构关联与原文写法分别保存

2026-09-18，用户选择全称使用 [公司1]、简称使用 [公司1]① 的方式：同一机构共用主体编号，每种原文写法分别对应唯一代号，同一称呼指向同一机构时重复使用该代号。圈号表示原文写法不同，不表示另一家机构；确定指机构但没有全称的简称仍独立脱敏。

现有全称、简称共用代号的做法已复现还原丢失：立即还原全部成为全称，映射保存重载后全部成为简称。采用现有附加序号机制的样例则可准确还原。未选择全称简称显示完全相同、依赖逐次位置恢复原文的方案，因为它需要额外处理文档编辑后的定位变化。

这项决定影响脱敏文档和持久化映射，后续修改必须考虑已生成文件的兼容性。不得仅为统一显示重新合并原文写法；旧映射已经丢失的区别不能凭升级自动恢复。
