## 🧐 这是什么

这是一个**默认完全在你自己电脑上运行**的文档处理工具（也支持可选的在线 API 模式）。它能自动找出文档里的：

- 🏢 **机构名称**（比如公司名、集团名、协会名、医院名、政府机关名等）
- 👤 **人名**（文档里出现的人名）
- 📍 **地址**（省市、区县、街道等地理名称）
- 📱 **手机号**（中国手机号、带国际区号的手机号）
- ☎️ **座机号**（国内座机、国际座机，含分机号）
- 🆔 **身份证号**（18位，含X校验位）
- 📧 **电子邮箱**（各种格式的邮箱地址）
- 🚗 **车牌号**（中国大陆车牌，含新能源车牌）
- 🌐 **IP地址**（IPv4格式）
- 🔗 **MAC地址**（网络设备物理地址）
- 💰 **精确金额**（百万元以上的大额财务数据，模糊化处理）
- 📅 **日期**（年月日精确日期，年份部分遮盖）
- 🏦 **银行账号**（16到19位数字）
- 🆔 **社会统一信用代码**（18位的字母数字组合）

找到之后，它会根据不同类型做不同的处理：

- **大部分类型**：替换成代号，比如 `张三` → `[人物1]`
- **金额**：模糊化处理，比如 `14,523,900.00元` → `1500万余元`（四舍五入到百万位，统一万元单位）
- **日期**：年份第3位遮盖 + 月日代号化，比如 `2024年3月15日` → `20X4年[日期1]`

换完之后，它会生成一张**映射表**（一个名叫"脱敏映射表.json"的文件）。以后你拿着这张表，可以一键把脱敏后的文档**还原回原文**。

### ✨ 核心特点

- ✅ **默认本地运行**——选择“本地 LM Studio”模式时不需要联网，数据不出本机
- ✅ **可选在线 API**——选择“在线 API”模式时会把待识别文本发送到你配置的接口（可能产生费用）
- ✅ **保留原始格式**——脱敏后的Word/Excel/PPT/PDF，排版和原来一模一样
- ✅ **可以还原**——只要映射表没丢，随时能恢复原文
- ✅ **批量处理**——一次可以处理整个文件夹，包含子文件夹也行
- ✅ **自动识别敏感信息**——不用你手动去翻找

## 📄 能处理哪些文件

| 文件类型 | 格式 | 说明 |
|---------|------|------|
| 📝 纯文本 | `.txt` | 记事本文件 |
| 📝 Markdown | `.md` | 写笔记、文档用的标记语言文件 |
| 📄 Word文档 | `.docx` | 新版Word文档（不支持旧版 `.doc`） |
| 📊 Excel表格 | `.xlsx` | 新版Excel表格（不支持旧版 `.xls`） |
| 📽️ PPT演示文稿 | `.pptx` | 新版PowerPoint文件（不支持旧版 `.ppt`） |

> ⚠️ **旧版格式说明**：`.doc`、`.xls`、`.ppt` 是微软 Office 2007 之前的旧格式，这个工具不支持。你可以用 Office 打开后另存为 `.docx`、`.xlsx`、`.pptx` 再处理。

## 💿 怎么安装

### 第一步：装 Python

1. 打开浏览器，去 Python 官网：https://www.python.org/downloads/
2. 下载最新的 Python（3.10 或以上都行）
3. 安装时**一定要勾选** "Add Python to PATH"（把Python添加到系统路径）
4. 安装完成后，打开"命令提示符"或"PowerShell"，输入 `python --version`，如果显示版本号就说明装好了

### 第二步：下载这个工具

把整个 `本地文档脱敏工具` 文件夹放到你喜欢的目录里，比如 `D:\我的工具\` 或者 `C:\Users\你的用户名\Documents\`。

### 第三步：安装依赖包

有两种方法：

#### 方法一：自动安装（推荐）

双击运行 `启动器.py`，程序会自动检测哪些依赖没装，弹窗问你要不要装，点"是"就行。

> ⚠️ 第一次运行可能需要等几分钟，因为要下载一些必要的程序包（总共几十兆），和你的网速有关。下载完成后，以后就不需要再联网了。
>
> 另外，人名/地名/机构名识别需要 LLM 后端：你可以用本地 LM Studio（推荐），也可以切到在线 API（需要联网，且可能收费）。配置方式见下面的"第五步"。

#### 方法二：手动安装

打开"命令提示符"或"PowerShell"，输入：

```bash
cd 你的工具存放路径\本地文档脱敏工具
pip install -r requirements.txt
```

### 第四步：确认装好了

在"命令提示符"里输入：

```bash
cd 你的工具存放路径\本地文档脱敏工具
python 维护工具\环境自检.py
```

如果看到"环境自检通过"就说明一切正常了。

### 第五步：配置 LLM 后端（本地/在线二选一）

#### 方案A：本地 LM Studio（推荐，离线）

LM Studio 用于本地 AI 识别人名、地名、机构名，也能处理扫描版 PDF。

1. 下载安装 **LM Studio**（免费）：https://lmstudio.ai/
2. 在 LM Studio 里搜索并下载一个中文模型（推荐 Qwen2.5 或 DeepSeek）
3. 启动 LM Studio，加载模型
4. 点击左侧的 **Local Server**（本地服务器）图标 → 点击 **Start Server**，保持它在后台运行

> 💡 程序启动后会自动检测 LLM 后端连接状态，界面上会显示绿色（已连接）或红色（未连接）的状态指示。未就绪不影响正则类脱敏，但人名/地名/机构名将不会被识别。
>
> 💡 **模型使用规则**：程序只会使用你在 LM Studio 里**当前已经加载好**的模型，不会替你切换模型，也不会改你的 LM Studio 设置。

#### 方案B：在线 API（需要联网，可能收费）

如果你不想/不能跑本地模型，可以切到“在线 API”模式，调用任意 OpenAI 格式兼容的接口。

1. 启动程序，在“LLM 配置”区切换到【在线 API】
2. 填写 API 地址（Base URL）、API 密钥（Key）和模型名（Model）
3. 点击【测试】或【拉取列表】验证连通性

> ⚠️ 如果既不配置本地 LM Studio，也不配置在线 API，脱敏功能仍然可以工作，但人名/地名/机构名将不会被识别（手机号、身份证号、金额等正则规则不受影响）。

### 🔐 脱敏操作（把敏感信息换成代号）

1. **选择输入**
   - 点击 **"选择文件"** 选一个文件，或者
   - 点击 **"选择文件夹"** 选整个文件夹
   - 如果要处理文件夹下的子文件夹，勾上 **"包含子文件夹"**

2. **选择输出位置（可选）**
   - 点击 **"选择目录"** 指定脱敏后的文件放在哪里
   - 不选的话，默认放到原文件所在目录
   - 点 **"清空"** 可以恢复成默认

3. **设置脱敏选项**（在控制栏中间）
   - **日期脱敏**：默认开启。关闭后日期不做处理
   - **含精确月日**：默认关闭。开启后月日替换为代号，关闭则仅遮盖年份数字（如 `2023年9月` → `20X3年9月`）
   - **金额脱敏**：默认关闭。开启后百万元以上金额模糊化处理
   - **简称强力审核**：默认关闭。开启后会用 LLM 审核更多“疑似机构简称”，能减少简称漏脱敏，但会增加调用次数且可能有误伤

4. **点击"开始脱敏"**
   - 程序会先扫描所有文件，找出敏感信息
   - 然后把敏感信息换成代号
   - 处理过程中，右边的日志框会实时显示进度

4. **处理完成后**
   - 生成的脱敏文件：原文件名后面多了"`_脱敏`"两个字
   - 同时会生成一个 `原文件名_脱敏映射表.json` 文件（这就是"密码本"，一定要保存好）
   - 非纯文本文件（`.docx`/`.xlsx`/`.pptx`/`.pdf`）还会额外生成一个 `原文件名_脱敏.md` 纯文本版本

**举个例子**：
```
有一个文件叫"合同.docx"
脱敏后会生成：
  ✅ 合同_脱敏.docx               ← 脱敏后的Word版，格式和原来一样
  ✅ 合同_脱敏映射表.json         ← 还原时要用到的密码本（每个文件独立一份）
  ✅ 合同_脱敏.md                 ← 纯文本版脱敏结果，方便查看
```

> 📌 **映射表是每个文件独立的**。如果批量处理多个文件，每个文件会各自生成自己的映射表（如 `合同_脱敏映射表.json`、`报告_脱敏映射表.json`）。一个文件的映射表不会污染另一个文件。

### 🔓 还原操作（把代号恢复成原文）

1. **选择要还原的文件或文件夹**
   - 和脱敏操作一样，点"选择文件"或"选择文件夹"

2. **点击"开始还原"**
   - 程序会自动根据脱敏文件的文件名，在它旁边找到对应的 `原文件名_脱敏映射表.json`
   - 比如 `合同_脱敏.docx` 会去找 `合同_脱敏映射表.json`
   - 如果映射表找不到，程序会提示你哪个文件找不到映射表

3. **还原完成后**
   - 生成的文件：原文件名后面多了"`_还原`"两个字
   - 内容恢复成了脱敏前的原文

**举个例子**：
```
脱敏后的文件叫"合同_脱敏.docx"
加上自动匹配到的映射表"合同_脱敏映射表.json"
还原后会生成：
  ✅ 合同_脱敏_还原.docx    ← 内容和原始合同一样
```

### ⏹️ 取消处理

如果处理过程中想中断，点 **"取消处理"** 按钮就行。已经处理完的文件不受影响。

## 🔍 详细功能说明

### 脱敏规则

这个工具会自动识别以下十四种敏感信息：

| 敏感信息类型 | 例子 | 脱敏后变成 |
|------------|------|-----------|
| 🏢 机构名称 | XX集团有限公司、XX研究院、XX局 | [公司1]、[事业单位2]、[机关3] |
| 👤 人名 | 张三、李四 | [人物1]、[人物2] |
| 📍 地址 | 北京市海淀区、上海市浦东新区 | [地址1]、[地址2] |
| 📱 手机号 | 13812345678、+14155552671、+447911123456 | [手机号1]、[手机号2]、[手机号3] |
| ☎️ 座机号 | 010-87654321、0755-12345678、+442071234567 | [座机号1]、[座机号2]、[座机号3] |
| 🆔 身份证号 | 110101199003076518、440301198512150012 | [身份证号1]、[身份证号2] |
| 📧 电子邮箱 | zhangsan@company.com | [邮箱1] |
| 🚗 车牌号 | 京A12345、沪AD12345 | [车牌号1]、[车牌号2] |
| 🌐 IP地址 | 192.168.1.1 | [IP地址1] |
| 🔗 MAC地址 | AA:BB:CC:DD:EE:FF | [MAC地址1] |
| 💰 精确金额 | 14,523,900.00元、1452.39万元 | 1500万余元（模糊化，可关闭） |
| 📅 日期 | 2024年3月15日、2024年3月 | 20X4年[日期1]（年份遮盖，可关闭、可仅遮年份） |
| 🏦 银行账号 | 6222021234567890 | [银行账号1] |
| 🆔 信用代码 | 91110000MA12345678 | [信用代码1] |

> 💰 **金额脱敏说明**：只处理百万元以上的金额。精确金额会被银行家舍入（四舍六入五成双）到百万位，统一换算成"万元"为单位，末尾加"余"字。比如 `14,523,900.00元` → `1500万余元`，`3.5亿元` → `35000万余元`。低于百万的金额不会被处理。Excel中的数值型单元格金额不脱敏（保持精确）。当多个不同金额模糊化后相同时（碰撞），会自动追加序号区分（如 `300万余元`、`300万余元①`、`300万余元②`），确保还原时不会混淆。

> 📅 **日期脱敏说明**：只处理包含年月日或年月的完整日期。年份第3位数字会被替换为X（如2024→20X4），月日部分替换为代号。还原时可以恢复原始精确日期。

> 注意：同一个名字在整个文档里会被换成同一个代号。比如全文有10处"张三"，全部变成"[人物1]"。

### 机构子类型

不同的机构会被自动分类成不同的子类型，分别编号：

- 🏢 **公司类**：XX公司、XX集团、XX合伙企业
- 🏛️ **机关类**：XX局、XX厅、XX部、XX委、XX办、XX处、XX署
- 🏫 **事业单位类**：XX研究院、XX中心、XX馆、XX站、XX社、XX院
- 🤝 **协会类**：XX协会、XX学会、XX联合会、XX商会、XX促进会、XX基金会
- 🏠 **其他机构**：上面没列出的其他机构名

这样编号不会混在一起，比如 `[公司1]` 和 `[机关1]` 不会冲突。

### 扫描版PDF处理流程

如果你的PDF是扫描版（图片格式），处理流程是这样的：

1. 程序先判断PDF是不是扫描版（根据里面有没有可选中的文字）
2. 如果是扫描版，调用当前 LLM 后端（本地 LM Studio 或 在线 API）进行 "看图片认字"
3. 认出文字后，再进行脱敏
4. 因为扫描版PDF无法直接修改原文件里的文字，所以只会输出一个纯文本版本

> ⚠️ 扫描版PDF脱敏后**不会**生成 `_脱敏.pdf` 文件，只会生成 `_脱敏.md` 纯文本文件。

## ⚙️ 运行逻辑（原理）

这个工具采用**每个文件独立处理**的流水线。每个文件按顺序逐个走完以下流程：

```
原始文件 → 提取文字 → AI识别敏感信息 → 建立独立映射表 → 脱敏替换 → 输出脱敏文件 + 映射表
                                                                      ↓
                                                          文件名_脱敏映射表.json
```

处理完一个文件后，**立即输出**脱敏文件和映射表。如果中途取消或遇到错误，已经处理完的文件不受影响。

### 每个文件的处理步骤

1. **提取文字**：根据文件格式，提取里面的可识别文字内容
2. **AI识别人/地/机构**：用 LLM 后端（本地 LM Studio 或 在线 API）自动识别人名、地名、机构名
3. **实体脱壳生成简称**：从AI识别出的每个机构全名出发，逐层剥掉外壳（法律后缀→地名标记→行业词），生成核心简称，直接注册到映射表
4. **正则找简称**：扫描原文中带机构后缀的词语，检查是否为已确认实体的子串，匹配到的自动注册
5. **正则规则匹配**（结构化脱敏）：
   - 手机号、座机号、身份证号、邮箱、车牌号、IP地址、MAC地址、银行账号、信用代码
   - 精确金额（百万以上），银行家舍入到百万位
   - 日期，年份遮盖 + 月日代号化
6. **建立独立映射表**：该文件内的敏感信息分配独一无二的代号，保存在该文件独有的映射表里
7. **脱敏写入**：用 AC 自动机多模式匹配，一键替换全文所有命中项，保持原始格式
8. **输出**：脱敏文件 + `原文件名_脱敏映射表.json`

#### 简称识别的两条路

简称识别是整个工具最复杂的环节。LLM能认出"闻喜县新佳新能源有限公司"这个全名，但文中大量出现的"闻喜新佳""特变电工"等简称，LLM往往不会主动标注。程序通过两条互补路线来补漏：

**路线A：正则去原文里"找"**

正则扫描原文，找出所有以"公司/电力/能源/发电/基金/数据……"等机构后缀结尾的词语，然后逐个问：

> 这个词是不是某个已知实体的"片段"？

```
"山西地方电力" 是 "山西地方电力有限公司" 的子串 → ✓ 自动注册
"目标公司" 不是任何实体的子串 → ✗ 丢弃（AI在线时跳过LLM审核）
```

这条路受限于后缀词典——没有后缀的简称（如"闻喜新佳"末尾是"新佳"而非"公司"）正则根本看不见。

**路线B：从实体名脱壳"生成"**

不依赖正则扫描原文，直接从AI已确认的每个实体全名出发，剥掉外壳：

```
"闻喜县新佳新能源有限公司"
  → 洗法律后缀：去掉 "有限" → "闻喜县新佳新能源公司"
  → 洗公司后缀：去掉 "公司" → "闻喜县新佳新能源"
  → 洗地名标记：去掉 "县"   → "闻喜新佳新能源"      ← 第一轮产物
  → 洗行业词：  去掉 "新能源" → "闻喜新佳"            ← 第二轮产物（仅公司类实体）
```

两轮产物都注册到映射表，AC自动机在原文中命中即替换。

**两条路的关系：互补**

| | 路线A（正则找） | 路线B（实体脱壳） |
|---|---|---|
| 从哪里出发 | 扫描原文 | 从已知实体名出发 |
| 抓"山西地方电力" | ✓（后缀"电力"） | ✓（脱壳产物） |
| 抓"闻喜新佳" | ✗（无匹配后缀） | ✓ |
| 筛选方式 | 子串/清洗后匹对 | 直接注册 |
| 产出垃圾 | 有（被白名单过滤） | 无 |

两条路的产出**汇总到同一张映射表**，AC自动机统一处理。路线A抓到而路线B漏了的，路线B补；路线B生了但原文没出现的，AC自动机不会命中——无副作用。

**AI优先原则**

路线A中的"LLM审核未知候选"步骤，只在AI完全离线或一个实体都没产出时才启用。正常工作时只做安全的父实体匹配，不做冒险的LLM审核，防止正则引入误伤。

**简称的代号分配与还原**

简称在映射表中**不共享**主实体的代号，而是分配带圈数字序号的独立代号（与金额碰撞防丢机制相同）：

```
映射表：
  "闻喜县新佳新能源有限公司" → [公司4]        ← 全名，主代号
  "闻喜新佳"                 → [公司4]①      ← 简称，独立代号
  "特变电工"                 → [公司1]①      ← 简称，独立代号
```

脱敏后原文变成 `[公司4]（以下简称"[公司4]①"）`，还原时：
- `[公司4]` → 闻喜县新佳新能源有限公司
- `[公司4]①` → 闻喜新佳

简称和全名各自归位，不会混成一团。

### Excel 文件的特殊处理

Excel 表格中数值型金额单元格不脱敏（保持精确值）。提取文字时，纯数字单元格和含金额单位的文本不会送给 AI 识别，避免数量巨大的数字行占用不必要的模型调用时间。

### 还原逻辑

还原是脱敏的逆过程：

1. **自动匹配映射表**：根据脱敏文件的文件名，在同一目录下自动找到对应的 `原文件名_脱敏映射表.json`
2. 用映射表把文件里的所有代号替换回原文
3. Word/Excel/PPT/PDF 同样保持原始格式

> 📌 **为什么换成单文件独立映射表？** 如果多个文件一起处理，各自使用独立的映射表。同一个敏感信息（如"张三"）在不同文件中可以有不同的代号（文件A中是`[人物1]`，文件B中可能是`[人物5]`）。这样即使某个文件的映射表丢失或被泄露，其他文件不受影响。同时每个文件处理完立即输出结果，不会出现"全部处理后才能拿到成果"的问题。

## ❓ 常见问题

### ❔ 处理完的文件还有敏感信息吗？

如果处理过程没有报错，所有被识别的敏感信息都会被替换成代号。但要注意：
- 人名识别不是100%准确的，可能会有漏掉的情况
- 如果文档里有图片（图片里的文字），普通模式下是识别不了的

所以建议：脱敏后自己再快速检查一遍。

### ❔ 我的数据会被传到网上吗？

**绝对不会**。这个工具完全在你自己的电脑上运行：
- 不需要联网
- 不使用任何云服务
- 所有AI模型都是本地运行的

### ❔ 映射表丢了怎么办？

每个文件都对应着自己独立的 `文件名_脱敏映射表.json`。如果某个文件的映射表丢了，**这个文件就无法还原了**。建议：
- 把每个脱敏文件旁边的 `*_脱敏映射表.json` 单独备份到安全的地方
- 不要随便改名或修改里面的内容
- 好在每个文件是独立的，丢了一个不影响的文件的映射表

### ❔ 可以批量处理多少个文件？

没有数量限制。但是文件越多、越大，处理时间就越长。几百兆的大文档可能需要几分钟。

### ❔ 为什么启动时报错说找不到某些东西？

第一次使用需要先安装依赖包。运行 `启动器.py` 时会自动检测和提示安装，或者你也可以手动运行：

```bash
pip install -r requirements.txt
```

### ❔ 扫描版PDF必须用LM Studio吗？

不一定。扫描版 PDF 必须依赖 LLM 后端处理（本地 LM Studio 或 在线 API 二选一）。如果当前选定的后端未就绪，扫描版 PDF 会被拦截并提示你先把后端配置好。

### ❔ 为什么有些Word文档里的文字没有被替换？

之前（2026-05-23之前版本）Word文档里的文字可能分在多个"运行块"里（比如"四川和邦"和"生物科技股份有限公司"在不同的块里），如果敏感信息被拆散在不同的 `<w:t>` 元素里，老版本会漏掉不替换。

**2026-05-23已修复**：替换逻辑已改为**段落级替换**——先把段落里所有 `<w:t>` 的碎片文本拼成完整句子，再对整个句子做匹配替换，最后按比例分配回各 `<w:t>`。跨运行块的实体也能正确替换了。
